# Portfolio Website - Akhil Babu

A modern, interactive portfolio website showcasing skills in Flutter Development, Cloud Architecture, and DevOps. Built with HTML, CSS, and JavaScript, featuring a stunning 3D particle background animation and glassmorphism design.

## ✨ Features

- **🎨 Modern Glassmorphism Design**: Sleek, modern UI with glass-like transparent elements and blur effects
- **🌌 3D Particle Background**: Interactive particle network animation built with Three.js
- **📱 Fully Responsive**: Optimized for all devices - mobile, tablet, and desktop
- **🎯 Smooth Navigation**: Fixed header with smooth scroll navigation
- **📧 Contact Form**: Integrated contact form using FormSubmit.co
- **🎭 Interactive Elements**: Hover effects, smooth animations, and transitions
- **⚡ Fast & Lightweight**: Optimized performance with minimal dependencies
- **🎨 Custom Branding**: Personalized with gradient text effects and modern typography

## 🛠️ Technologies Used

### Frontend
- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with CSS variables, flexbox, and grid
- **JavaScript (ES6+)**: Interactive functionality and DOM manipulation

### Libraries & Frameworks
- **Three.js**: 3D graphics and particle system
- **Vanta.js**: Enhanced background effects
- **Google Fonts (Inter)**: Clean, modern typography

### Services
- **FormSubmit.co**: Contact form handling without backend

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server or build tools required!

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Akhi1Babu/NestDevopsInternship.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd NestDevopsInternship
   ```

3. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local development server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js (with npx)
     npx serve
     ```

4. **View the website**
   - Direct file: Open `index.html` directly in your browser
   - Local server: Navigate to `http://localhost:8000`

## 💡 Usage

### Sections

1. **Home/Hero Section**
   - Introduction with name and tagline
   - Call-to-action buttons for navigation

2. **Skills Section**
   - Three main expertise areas:
     - Flutter Development & AI
     - Cloud Architecture
     - DevOps & Backend

3. **About Section**
   - Brief professional introduction
   - Background and expertise overview

4. **Contact Section**
   - Functional contact form
   - Form submissions sent to configured email
   - LinkedIn and GitHub social links

### Customization

#### Update Personal Information
Edit `index.html`:
- Change name in the logo and hero section
- Update skills and expertise descriptions
- Modify social media links in the footer
- Update email in the contact form action

#### Modify Styling
Edit `style.css`:
- Adjust CSS variables in `:root` for theme colors
- Modify glassmorphism effects
- Change layout and spacing

#### Enhance Animations
Edit `background.js`:
- Adjust particle count and size
- Modify rotation speeds
- Change colors and opacity

## 📧 Contact Form Setup

The contact form uses [FormSubmit.co](https://formsubmit.co/), a free form backend service.

**To configure for your email:**
1. Open `index.html`
2. Find the form tag in the Contact section
3. Replace `akhilb732@gmail.com` with your email in the form action attribute:
   ```html
   <form action="https://formsubmit.co/YOUR_EMAIL@example.com" method="POST">
   ```

## 📱 Responsive Design

The website is fully responsive with breakpoints for:
- **Desktop**: 1200px and above (default)
- **Tablet**: 768px - 1199px
- **Mobile**: Below 768px (hamburger menu activated)
